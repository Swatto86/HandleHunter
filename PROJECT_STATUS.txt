NEXT STEPS:
===========

1. Verify GCC is installed:
   - Open Command Prompt (cmd.exe)
   - Run: test_gcc.bat
   
2. If GCC is not found:
   - Install MinGW-w64: winget install mingw-w64
   - Or download from: https://www.mingw-w64.org/downloads/
   - Add to PATH: C:\mingw64\bin (or wherever you installed it)

3. Build the project:
   - Open Command Prompt (cmd.exe) in this directory
   - Run: build.bat
   - This will create HandleHunter.exe

4. Clean build artifacts:
   - Run: build.bat clean

KNOWN ISSUES:
=============

- PowerShell has issues with batch files - always use cmd.exe
- If manifest embedding fails, the app will still work but you'll need
  to manually "Run as Administrator"

ARCHITECTURE:
=============

main.c → WinMain() → CreateMainWindow() (gui.c)
         ↓
    Message Loop
         ↓
    MainWindowProc() (gui.c)
         ↓
    Event Handlers:
      - OnConnect() → EnumerateOpenFiles() (netapi.c) → LockArray_Add() (lockinfo.c)
      - OnRefresh() → EnumerateOpenFiles() (netapi.c) → UpdateListView() (gui.c)
      - OnReleaseLock() → CloseFileLock() (netapi.c) → OnRefresh()

COMPILATION ORDER:
==================

1. main.c     → main.o
2. gui.c      → gui.o  
3. netapi.c   → netapi.o
4. lockinfo.c → lockinfo.o
5. Link all .o files → HandleHunter.exe
6. Embed manifest (optional)

REQUIRED LIBRARIES:
===================

- netapi32.lib  (NetFileEnum, NetFileClose)
- comctl32.lib  (ListView, StatusBar)
- kernel32.lib  (automatically linked)
- user32.lib    (automatically linked)
- gdi32.lib     (automatically linked)

All libraries are included with MinGW-w64.
