========================================
HandleHunter - Complete Build Instructions
========================================

STEP 1: Verify All Files Are Present
=====================================

Run this command in Command Prompt:
  verify_files.bat

This will check that all required source files exist.


STEP 2: Install MinGW-w64 (if not already installed)
====================================================

Option A - Using winget (easiest):
  winget install mingw-w64

Option B - Manual download:
  1. Go to: https://www.mingw-w64.org/downloads/
  2. Download the installer
  3. Install to C:\mingw64 (or any location)
  4. Add C:\mingw64\bin to your PATH environment variable

To add to PATH:
  1. Search Windows for "Environment Variables"
  2. Click "Environment Variables"
  3. Under "System variables", find "Path"
  4. Click "Edit"
  5. Click "New"
  6. Add: C:\mingw64\bin (or wherever you installed it)
  7. Click "OK" on all dialogs
  8. Close and reopen Command Prompt


STEP 3: Test GCC Installation
==============================

Run this command in Command Prompt:
  test_gcc.bat

If it shows GCC version info, you're ready to build!
If it says "gcc not found", repeat Step 2.


STEP 4: Build HandleHunter
===========================

IMPORTANT: Use Command Prompt (cmd.exe), NOT PowerShell!

To build:
  build.bat

Expected output:
  ========================================
  Building HandleHunter...
  ========================================
  
  [1/4] Compiling main.c...
  [2/4] Compiling gui.c...
  [3/4] Compiling netapi.c...
  [4/4] Compiling lockinfo.c...
  Linking HandleHunter.exe...
  
  ========================================
  Build successful!
  ========================================
  Output: HandleHunter.exe

The build creates these files:
  - main.o
  - gui.o
  - netapi.o
  - lockinfo.o
  - HandleHunter.exe (the final program)


STEP 5: Run HandleHunter
=========================

CRITICAL: HandleHunter MUST be run as Administrator!

To run:
  1. Right-click HandleHunter.exe
  2. Select "Run as administrator"
  3. Click "Yes" on the UAC prompt

Or from Command Prompt (as Administrator):
  HandleHunter.exe


TROUBLESHOOTING:
================

Problem: "gcc is not recognized as an internal or external command"
Solution: MinGW-w64 not installed or not in PATH. See Step 2.

Problem: "Access denied" when running HandleHunter
Solution: Must run as Administrator. Right-click → Run as administrator.

Problem: "Server not found" error
Solution: 
  - Check server name is correct
  - Try using IP address instead: \\192.168.1.100
  - Verify network connectivity: ping SERVERNAME
  - Ensure SMB is enabled

Problem: Build fails with "undefined reference to..."
Solution: 
  - Clean build: build.bat clean
  - Rebuild: build.bat
  - If still fails, check that netapi32 and comctl32 libraries exist

Problem: Batch file doesn't work properly
Solution:
  - Make sure you're using cmd.exe, NOT PowerShell
  - Open fresh Command Prompt window
  - Navigate to project directory: cd C:\Users\Swatto\HandleHunter
  - Run: build.bat

Problem: "manifest not embedded" warning
Solution:
  - This is OK - the app will still work
  - You'll just need to manually "Run as administrator"
  - To fix: Install Windows SDK (includes mt.exe)


CLEAN BUILD:
============

To remove all build artifacts:
  build.bat clean

This deletes:
  - All .o files (main.o, gui.o, netapi.o, lockinfo.o)
  - HandleHunter.exe


MANUAL BUILD (if batch file doesn't work):
===========================================

Open Command Prompt and run these commands one by one:

gcc -O2 -Wall -DUNICODE -D_UNICODE -c main.c -o main.o
gcc -O2 -Wall -DUNICODE -D_UNICODE -c gui.c -o gui.o
gcc -O2 -Wall -DUNICODE -D_UNICODE -c netapi.c -o netapi.o
gcc -O2 -Wall -DUNICODE -D_UNICODE -c lockinfo.c -o lockinfo.o
gcc main.o gui.o netapi.o lockinfo.o -o HandleHunter.exe -mwindows -lnetapi32 -lcomctl32 -s

If all commands complete without errors, you'll have HandleHunter.exe


WHAT THE FLAGS MEAN:
====================

Compiler flags (-CFLAGS):
  -O2           Optimize for speed
  -Wall         Show all warnings
  -DUNICODE     Enable Unicode (wide characters)
  -D_UNICODE    Enable Unicode (alternative macro)
  -c            Compile to object file (don't link yet)

Linker flags (-LDFLAGS):
  -mwindows     Create GUI application (no console)
  -lnetapi32    Link NetAPI library (NetFileEnum, NetFileClose)
  -lcomctl32    Link Common Controls library (ListView, StatusBar)
  -s            Strip symbols (smaller executable)


PROJECT STATISTICS:
===================

Total Lines of Code: ~1,500
Total Source Size:   ~58 KB
Executable Size:     ~100 KB (after compilation)
Compilation Time:    ~5 seconds (on modern PC)


USAGE TIPS:
===========

1. Always run as Administrator
2. Server name format: SERVERNAME or \\SERVERNAME
3. Local server: Use "." or "localhost" or leave blank
4. Search works on: filename, path, and username
5. Double-click a file to release its lock (after confirmation)
6. Refresh (F5) to update the file list


ARCHITECTURE OVERVIEW:
======================

main.c:
  - WinMain() - Entry point
  - OnConnect() - Connect button handler
  - OnRefresh() - Refresh button handler
  - OnReleaseLock() - Release lock handler
  - OnSearchChanged() - Search box handler

gui.c:
  - CreateMainWindow() - Create main window
  - CreateControls() - Create all UI controls
  - MainWindowProc() - Main message handler
  - UpdateListView() - Update file list display

netapi.c:
  - EnumerateOpenFiles() - Get list of open files
  - CloseFileLock() - Close a file handle
  - TestServerConnection() - Test server connectivity

lockinfo.c:
  - LockArray_Init() - Initialize dynamic array
  - LockArray_Add() - Add item to array
  - LockArray_Clear() - Clear array
  - LockArray_Free() - Free array memory


NEXT STEPS:
===========

After successfully building and running HandleHunter:

1. Test on a non-production server first
2. Verify you can see open files
3. Test the search functionality
4. Try releasing a lock (test file recommended)
5. Use on production servers to resolve file lock issues
