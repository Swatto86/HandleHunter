IMPORTANT NOTES:
================

⚠ Use Command Prompt (cmd.exe), NOT PowerShell for building!
⚠ HandleHunter MUST be run as Administrator!
⚠ Requires MinGW-w64 (GCC compiler) to build


IF BUILD FAILS:
===============

1. Make sure GCC is installed:
   winget install mingw-w64

2. Make sure you're in Command Prompt (cmd.exe), not PowerShell

3. Try cleaning first:
   build.bat clean
   build.bat

4. If all else fails, see BUILD_INSTRUCTIONS.txt for manual build


BUILD OUTPUT:
=============

After successful build, you'll have:
  HandleHunter.exe   - The application (~100 KB)
  main.o             - Object file

  netapi.o           - Object file
  lockinfo.o         - Object file


HOW TO RUN:
===========

Right-click HandleHunter.exe → Run as administrator


USAGE:
======

1. Enter server name (e.g., FILESERVER01)
2. Click "Connect"
3. See all open files in the list
4. Use search box to filter
5. Select a file and click "Release Selected Lock" to close it


TESTING:
========

Test on a non-production server first!

  ✓ See open files
  ✓ Search and filter
  ✓ Release a lock
